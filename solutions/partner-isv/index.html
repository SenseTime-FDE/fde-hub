PARTNER ISV·小浣熊企服版

伙伴 ISV 方案N ＋ X · 分行业与场景

行业方案与场景 Agent，由伙伴 ISV 基于 Raccoon X 提供。

4+N+X 里的 N ＋ X 主要由伙伴 ISV 提供：N 是按行业组织的方案，X 是按业务场景搭建的 Agent。都基于 Raccoon X 开发，上架小浣熊企服版，与商汤小浣熊共用一套知识库、Memory 与 Token 计量；客户按 Token 用量付费。

01N · BY INDUSTRY

N · 行业方案：按行业组织

伙伴 ISV 提供 N 个行业的方案。

谁提供

深耕行业的伙伴 ISV

做行业方案的实施、定制与运营。

怎么做

基于 Raccoon X 开发

不自建底座，与商汤小浣熊共用一套知识库、Memory、统一权限与审计。

怎么上架

上架小浣熊企服版

统一品牌、统一入口，客户按 Token 用量付费。

02X · BY SCENARIO

X · 场景 Agent：按业务场景组织

伙伴 ISV 基于 Raccoon X 搭建 X 个 Agent，按需组合。

是什么

面向具体场景的 Agent

基于 Raccoon X 搭建，读同一套知识库与 Memory。

怎么用

按需组合

与商汤小浣熊、行业方案组合使用。

怎么计量

Token 统一计量

调用经 MaaS 平台，按 Token Plan 或 Token API 计量。

加入方式

加油送车：伙伴的行业方案与 Agent 是「车」，商汤提供 Token 做「油」，客户按用量付费。
