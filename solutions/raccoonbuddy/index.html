小浣熊企服版RaccoonBuddy

企业真正的AI伙伴，业务场景即刻落地

商汤小浣熊企服版：4+N+X 应用 ＋ Raccoon X 智能体平台 ＋ MaaS 平台，整套可私有化，也提供云端 SaaS 多租户；模块可单独采购，也可整体交付。

「真正服务企业的 xBuddies，多场景AI业务伙伴，可横向扩展销售、人力、运营、客服、IT等模块」

01PAIN POINTS

企业 AI 落地，卡在六个断点

不缺模型，缺的是把 AI 接进业务、管进组织、算清成本的一整套产品。

01

销售过程看不见

  • 客户优先级缺少共同依据，商机卡点散落在沟通里
  • 有效判断依赖少数资深人员，难以复盘

对应SalesBuddy

02

项目管不住

  • 售前、交付、产品各记各的，串不成一条线
  • 关口无签字，验收无证据

对应ProjectBuddy

03

AI 停留在个人工具

  • 员工各用各的 AI 辅助工具，组织里接不起来
  • 目标、任务、项目与 Agent 不打通

对应Raccoon X 智能体平台

04

知识与记忆不通，Know-How 未沉淀

  • 图表、截图、录音里的知识查不到
  • 每个 Agent 各记各的，人走经验也走
  • 可配置的 Skill/Prompt，将好的经验沉淀

对应RAG 知识库、Memory 与 Skill/Prompt

05

待办散在各处

  • 飞书、钉钉和各系统里的待办没人承接
  • 谁在做、做到哪，要层层追问

对应Raccoon X 工作台

06

模型与成本算不清

  • 各部门各买各的模型和 Key，账算不清
  • 想全员用 AI，又怕用量失控

对应MaaS 平台

小浣熊企服版

六个断点由 4+N+X 应用、Raccoon X 与 MaaS 平台 一起解决；模块可单独采购，也可整体交付。

03HIGHLIGHTS & VALUE

方案亮点与对客价值

01

岗位 Agent 团队

专家智能体服务 AI Native，岗位助理协同工作，现在就能落地。

02

目标任务项目打通

目标、任务 Action 与售前、交付、产品的项目管理连成一条线。

03

一套知识库与 Memory

多 Agent 之间知识库打通、Memory 打通，人走资产留。

04

Prompt / Skill 自配

用户端自己配置助理，业务人员也能用好 Agent。

05

MaaS 一站式

Token Plan、API、智能体与应用开发；国内、海外，SaaS 或私有化。

06

可整可拆

小浣熊、Raccoon X、MaaS 平台可单独采购，也可整体交付。

对谁有什么价值

企业经营者客户、经验与流程沉淀为企业资产，人走资产留；每个数字可追溯。
业务负责人对团队说目标，Agent 团队按组织推进；卡点早暴露，交付有证据。
IT 与数字化整套可私有化；模型、权限、审计一套管。
财务用量可度量、预算可分配、账单可追溯。
一线员工待办有人接，Prompt 与 Skill 自己配；人专注判断与见客。
生态伙伴应用上架即接入商汤底座与客户，以加油送车分享收益。
一句话

不止 AI 辅助工具：能跑在组织里的 Agent 团队，模块可单独采购、整套可私有化。

04HOW TO BUY

三种采购组合：整体交付，也可从一个模块切入

整体采购

小浣熊企服版全套

  • 商汤小浣熊 ＋ Raccoon X ＋ MaaS 平台
  • 整套私有化或云端 SaaS 多租户
  • 适合：一次规划销售、项目与团队 AI 的企业

从应用切入

一个 Buddy ＋ 平台

  • SalesBuddy 或 ProjectBuddy 先跑起来
  • 配 Raccoon X 与 Token Plan
  • 适合：有明确业务场景、想先见效的企业

从平台切入

MaaS ＋ Raccoon X

  • Token Plan 与 API 统一接入模型
  • 在 Raccoon X 上自建智能体与应用
  • 适合：有开发团队、想自建场景的企业
