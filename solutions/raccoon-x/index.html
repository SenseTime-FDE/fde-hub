01核心能力·CAPABILITIES

从一个助手，到一套业务应用。

按任务的复杂度选择合适的方式，也可以让 Agent、专家团队与流程相互配合。

A SPECIALIST FOR YOUR WORK

给每一类工作，配一个专业助手。

从资料整理、专业问答到销售材料准备，为助手明确职责，再配上它需要的模型、知识和工具。业务人员用自然语言提出任务，也可以继续追问和调整结果。

  • 用提示词定义职责、处理规则与输出格式
  • 按需组合参考文件、Skills、工具与知识检索
  • 配置后发布，通过 Web 入口使用并持续迭代

适合：资料整理、材料起草、产品问答、销售准备。

EXPERTS WORKING TOGETHER

让不同专家，各尽所长。

当任务需要多个视角时，由团长安排分工、检查意见并汇总成果。专家各自承担提取、分析、复核等职责，让工作在团队里接续。

  • 从已发布 Agent 中选择团长与专家
  • 明确任务目标、专家分工与最终答案要求
  • 查看协作过程、成员执行情况与汇总结果

适合：多角度分析、资料交叉核对、报告协作。

REPEATABLE BUSINESS FLOWS

把成熟做法，变成可重复的流程。

用节点、连线和变量，把输入、模型、Agent、知识检索与输出串起来。Workflow 处理步骤明确的任务；Chatflow 在流程中承接多轮对话。

  • 按业务需要组合处理节点、条件分支和工具
  • 在画布上配置执行路径与数据传递
  • 测试运行、检查结果，再发布给业务使用者

适合：标准化资料处理、重复业务任务、多轮知识问答。

产品界面来自演示环境，示例资料为虚构内容；功能与界面以交付版本和账号权限为准。

05常见问题·FAQ

关于 Raccoon X，你可能想了解。

选好起点，让应用围绕实际业务任务逐步生长。

该选 Agent、Agent Teams，还是 Workflow？

单一职责、需要继续追问的任务，可以从 Agent 开始；需要多个专家交叉分析和复核时，选择 Agent Teams；执行路径明确、需要重复运行时，选择 Workflow。需要多轮对话与流程控制时，可选 Chatflow。

知识库和 Skills 有什么区别？

知识库提供回答和分析的资料依据，Skills 提供处理任务的方法与规范。两者可以同时配置给 Agent：先找到相关资料，再按既定方法完成工作。

能接入飞书、企业微信和已有系统吗？

Agent 与 Agent Teams 提供消息渠道配置入口；平台也支持 Web 应用与服务 API。飞书、企业微信等渠道需要管理员完成应用配置、授权和联调，具体可用范围以交付版本及企业配置为准。

怎样从一个小场景开始？

先选择资料整理、制度问答或销售材料准备等边界清晰的任务，准备资料与验证样例，跑通一个 Agent。再按需要增加知识库、Skills，或扩展为专家团队与工作流。
