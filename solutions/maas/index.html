产品与方案/小浣熊企服版/MaaS 平台

MAAS PLATFORM·小浣熊企服版

MaaS 平台国内 · 海外 · 私有化

一个入口，模型与用量管到人。

小浣熊企服版的 MaaS 平台：API 网关统一接入模型，Token Plan 账户体系把权益逐级分配到人，计量｜计费｜账单｜支付一本账，内含 Raccoon X 智能体编排；可随企服版私有化部署，也提供云端 SaaS 多租户。

解决什么问题

模型接入分散每个模型一套 Key 与调用方式。
用量说不清预算难分配，成本难回溯到人。
开发平台重复建智能体与应用开发各起一套。
数据不能出企业部分业务有合规与本地化要求。

产品逻辑

1一个入口API 网关统一接入，一个账号、一个 API Key。
2多模型可选SenseNova 日日新、开源与第三方大模型、本地模型，按需选择，换模型只改模型名。
3Token Plan 四层账户集团 → 分子公司 → 部门 → 个人，逐级分配。
4计量 · 计费 · 账单 · 支付用量计量到人，账单可对，订阅或充值支付。
5一站式开发含 Raccoon X 编排：智能体开发与应用开发。

带来的价值

✓一次接入，换模型只改模型名
✓额度逐级分配，预算可管控
✓从模型调用到智能体与应用，一个平台到底
✓可随企服版私有化，数据不出企业

01API GATEWAY

API 网关：一次接入，多模型可选

  1. 01

    调用方

    业务系统、编程工具、智能体，统一用一个 API Key。

  2. 02

    API 网关

    鉴权、路由、限流，按模型名分发。

  3. 03

    模型

    SenseNova、开源、第三方与本地模型，按需选择。

  4. 04

    Token Plan

    用量计入个人或部门权益，可查可对账。

02ACCOUNTS

Token Plan 四层账户：权益穿透到人

  1. 01

    集团

    统一采购，建组织树，向下级下发，看全集团用量。

  2. 02

    分子公司

    承接集团权益，开通部门，划拨与代开通。

  3. 03

    部门

    席位绑定到人，应用建 Key，按成员查询用量。

  4. 04

    个人

    一个席位与套餐额度，编程工具与 API 登录即用。
