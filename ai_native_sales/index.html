02

一把尺子：L0–L4 销售自主度，本方案交付 L3

先量级别，再谈方案——这把尺子也可以拿去量任何一家供应商

L0手工

找线索、跟进、记录、汇报全部人做，CRM 只是一张填报表单。

自主完成率0%
L1提示

AI 在旁边给建议、给话术、给模板，动作仍然全是人做。

自主完成率< 10%
L2代办

端到端完成单点任务，但要人逐个发起、逐个确认——目前大多数 AI 销售工具的天花板。

自主完成率20–40%
本方案交付位置
L3条件自主

端到端跑完一条业务链路：信号 → 判断 → 动作 → 留痕，只在四类节点找人。

自主完成率60–80%
L4高度自主

跨商机自主调配资源与人，人只定目标、边界与例外规则——路线图方向。

自主完成率> 80%

05

人机边界：只有四类节点必须找人

说得出规则的「找人」，才叫边界；说不出的，叫甩锅

🤝
要人脸出面
关系与信任无法委托，系统把人调度到场，并把该带的东西提前备好。
典型首访 · 关键谈判 · 高层拜访
✍️
要人担责
法律与商业责任必须落到自然人，系统只备料，不代签。
典型报价定案 · 合同签署 · 对外承诺
❓
AI 没把握
置信度低于阈值，宁可停下来问，也不硬猜着往前跑。
典型意图模糊 · 信息冲突 · 没见过的场景
📉
结果偏离
实际与预期偏差超过阈值，系统主动上报，而不是等人发现。
典型停滞超期 · 赢率骤降 · 客户降温
这四类之外，系统不找人。

这是 L3 与 L2 的分水岭：L2 工具每一步都要人点「确认」，人还是被拴在流程上。阈值、授权范围与例外规则由企业配置；每一次「找人」与「没找人」都留痕可审计。

06

管理界面：从看板，到待决队列

管理层每天打开系统的第一屏，不是一屏数字，是「今天需要你拍板的 N 件事」

人的工作量，从「分析」转移到「判断」

看板系统给数据 → 人分析 → 人决策 → 人派活
待决队列系统分析 → 系统给方案 → 人授权

每一条固定结构：事项 → Agent 的判断 → 依据（每条可回溯到原始记录与时间戳）→ 建议动作（具体到人和时间）→ 三个按钮。看板不取消，降级为审计与追溯入口——想验证 Agent 的判断对不对时才打开。

合规口径：队列中的依据引用自过程记录；过程数据用于赋能与组织沉淀，不用于监控个人，采集、保存、查看范围由企业规则配置。

六类能力子 Agent：主 Agent 手里的工具

是能力，不是「模块」——由商机主 Agent 按需调度，不对应任何一个人的岗位

🔍
研究与触达画像匹配、背调、决策链梳理、一户一稿的触达内容。
🎙
现场记录与理解拜访实时转写、分角色、需求与异议抽取。
📊
数据分析客户、商机、合同、纪要、案例、报价、竞品一个入口问到，返回带依据的结论。
📄
内容生成方案、标书、报价单、对外邮件。
⚖️
条款与风险合同逐条比对企业红线、投标合规与废标自检。
💰
回款与履约回款节点跟踪、逾期预警、履约里程碑。
能力不锁定：不绑定任何模型、不绑定任何 Agent，交付的是效果。同一任务可多方案并跑，按赢单贡献、成功率、人工纠偏率、成本自动择优；每个 Agent 每月一张能力记分卡，连续不达标就下架换掉。
