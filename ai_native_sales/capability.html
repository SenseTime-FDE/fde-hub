Capability Set · 六类能力 · 效果本位

能力是可替换的 —— 交付的是效果，不是型号清单

六类能力子 Agent 是商机主 Agent 手里的工具，不是给人用的六个模块：什么时候调、调哪一个、结果够不够好，都由主 Agent 按商机推进的需要决定，人不用记得它们存在。能力背后接的是哪个模型、哪套实现，随时可换 —— 同一任务多方案并跑、按效果择优、连续不达标就换掉。本页给出六类能力、客户点名的「数据分析」工作台，以及让「换掉」有据可依的能力记分卡。

01

六类能力子 Agent：主 Agent 什么时候调它，它交回什么

每一格的主语都是主 Agent —— 不是「销售可以用它做什么」

🔍
研究与触达
主 Agent 何时调它新商机建档当刻，以及每次判断「该触达了」的时候 —— 不等人想起来查资料。
它交回什么画像匹配与背调结论、决策链梳理、一户一稿的触达内容，直接写入商机档案。
🎙
现场记录与理解
主 Agent 何时调它人被调度到场的那几次（首访、二访、谈判），它随人进场，全程在线。
它交回什么拜访实时转写、分角色纪要、需求与异议抽取 —— 人走出会议室时，档案已经更新完。
📊
数据分析客户点名 · 下节展开
主 Agent 何时调它每一次「判」之前先问它；人也随时可以直接问，同一个入口。
它交回什么客户、商机、合同、纪要、案例、报价、竞品一个入口问到，返回带依据的结论，不是一堆报表。
📄
内容生成
主 Agent 何时调它里程碑推进到需要对外交付物时直接下发任务，不等人开始写。
它交回什么方案、标书、报价单、对外邮件的成稿；对外发出前按边界规则送人确认。
⚖️
条款与风险
主 Agent 何时调它合同或标书文本一出现、一变更，立即触发比对，不靠人送审。
它交回什么合同逐条比对企业红线的风险清单、投标合规与废标自检结果。
💰
回款与履约
主 Agent 何时调它签约当日自动把商机移交给它接管 —— 不需要任何人记得这件事。
它交回什么回款节点跟踪、逾期预警、履约里程碑；异常直接推进待决队列。
口径提醒

这是六种能力，不是六个「模块」：它们没有各自的首页和入口，不对应任何一个人的岗位。唯一的调用方是商机主 Agent，唯一的留痕是调用记录 —— 把它们画成组织架构里的六个格子，就又回到了「人的流程数字化」。

主 Agent 怎么「盯 · 判 · 调」这六类能力，看 商机与团队 →

客户点名能力单独展开 —— 四段式应答：结论 / 依据（带来源与时间戳）/ 风险 / 建议下一步

⊘ 本次查询已拦截 —— 你当前的角色无权查看华南区商机的报价数据。
  • 拦截即留痕：这次尝试作为一条权限事件记录在案，可被审计追溯。

权限矩阵由企业配置，系统只负责执行与留痕

按角色权限应答，越权拦截

同一个问题，不同角色，不同答案范围李芳问，看到全组；王强问，只看到自己名下。应答范围随角色走，不随话术走。
越权不是报错，是一条被记录的事件拦截、申请、授权、放行，全链路留痕可审计 —— 试试左侧王强那条查询。
敏感字段自动脱敏联系方式、报价、合同金额等字段，按企业规则脱敏后才进入模型调用。
模型调用不留存客户业务数据调用即用即走；数据的采集、保存、查看范围由企业规则配置。
合规边界：录音需提前告知参会方，录音原文默认仅销售本人可见；过程数据用于赋能与组织沉淀，不用于监控个人。
这个入口不只是给人用的：主 Agent 每一次「判」之前，先调它把信号问清楚 —— 人和主 Agent 引用的是同一套依据、同一条留痕。

为什么全站不写型号

本方案全套材料不出现任何模型型号名 —— 这不是遗漏，是立场：今天最好的型号，明天未必还是；把企业绑在某个型号上，等于绑在一个时间点上。交付承诺写在效果指标上，谁达标用谁。

实现 A · 在用 通用语言模型 + 标准生成链路 并跑期间照常出稿；每一稿是否被选中、被人改了多少，逐条记账。

对账维度实现 A（在用）实现 B（挑战）
定稿采用 —— 盲选中被选为终稿落后领先
人工纠偏 —— 定稿前被人改动的次数与幅度偏多更少
赢单贡献 —— 稿件进入投标与签约链路的占比落后领先
单位成本 —— 单次生成的合计成本更低偏高
判定

按企业配置的权重对账，赢单贡献与纠偏率优先于单次成本 —— 本例中实现 B 转正在用，实现 A 归档、可随时召回。切换由平台完成并留痕，主 Agent 的调用方式一个字不改，一线无感。
