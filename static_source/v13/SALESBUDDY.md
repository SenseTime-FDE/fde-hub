# SalesBuddy 产品页维护

本页范围是 `/solutions/salesbuddy/`。保持公共页眉、页脚、全站 CSS、其他产品页和 GitHub Pages 发布方式不变。

## 文件与生成

- `src/salesbuddy-content.js`：产品文案、五大能力、流程、角色、FAQ，以及工作台入口。
- `src/views/salesbuddy.js`：独立页面模板，复用原有 `layout.page()`。
- `public/css/salesbuddy-brand.css`：仅在 SalesBuddy 首屏加载的品牌标识样式，不影响其他产品页面。
- `public/css/salesbuddy.css`：页内样式，使用 `sb-` 前缀和原站设计变量。
- `public/js/salesbuddy.js`：首屏视频、能力切换、图片放大、页面导航和可选入口事件。
- `../../images/salesbuddy/`：本页产品图。
- `../../media/salesbuddy/`：本页小程序演示视频。

原有 `pages.product('salesbuddy')` 仅分派到此模板；其他产品维持原有渲染流程。原导出脚本新增复制本页两份资源，仍使用同一命令：

```sh
node scripts/export-v13-static.mjs
node scripts/validate-content.mjs
node scripts/validate-site.mjs
node --test
```

导出后，除本页 HTML 和专用资源外，其他页面应与修改前逐字节一致。

## 未来后端接入点（当前未启用）

1. 内容与渲染已分离。后续可以由服务端/CMS 提供相同内容结构，再交给当前模板；当前直接读取本地内容模块。
2. 工作台链接集中配置。无需改动模板布局即可更换正式入口。
3. 带 `data-sb-action` 的链接在常规点击时派发冒泡、可取消的 `salesbuddy:action` DOM 事件。`detail` 只有 `{ action, href }`；当前动作是 `open-workspace`，后续入口可复用同一事件。外部适配器可监听事件并调用 `preventDefault()`，接管登录跳转。没有监听器时保持原生链接行为，组合键仍按浏览器默认方式工作。
4. 本页不请求 API、不收集访客信息、不写入 localStorage，也没有虚构提交成功状态。未来表单、认证、存储和服务端校验由独立接入层实现，不在静态脚本中放置凭据。

以上仅预留本页扩展点，并未创建后端、改变登录流程或修改部署。

## 首屏展示

首屏参考产品官网的左右结构，左侧为介绍与入口，右侧为单个竖屏微信小程序演示视频；保留生态站原有暖白、深蓝、红色设计，小屏幕自然改为上下结构。

首屏品牌区使用用户于 2026-10-20 提供的销售小浣熊 Logo，保留透明背景、原有角色与配色，并压缩为 `images/salesbuddy/salesbuddy-logo.webp`。素材路径、尺寸与替代文字集中在 `heroLogo` 配置中。Logo 与中英文产品名并排显示，桌面为 64px、手机为 56px，沿用原有色彩和留白，不添加独立背景或动画。

首屏视频按用户于 2026-10-16 的要求由「视频」聊天修复转场模糊，来源为工作区 `视频剪辑/SalesBuddy_10秒首屏看板_清晰转场版.mp4`，页面素材保存在 `media/salesbuddy/miniapp-overview.mp4`。视频为 H.264、442 × 900、28 fps、10 秒、无音轨，保留经营概览、客户分布、商机看板、商机阶段与跟进图表、团队排行五个看板及原顺序。保留原片帧率与原速，采用清晰直切，不补帧、不叠化，也不含跟进记录录入片段。成片 1,613,202 字节，启用 MP4 fast start；剪辑端已验证 280 帧可解码，并核对切点两侧与各段中间帧无叠影。历史成片保留在工作区，不依赖外站在线播放。本地视频 SHA-256 为 `db5b0381b4bbc83e48fde3219cb255e162a7f5fff8165a93acb950b0108ea965`，播放地址附带短哈希以刷新缓存。

封面采用该清晰版成片的首帧经营概览画面，以原尺寸保存为 JPEG，封面地址也附带短哈希以刷新缓存；路径与尺寸集中在 `heroVideo` 配置，视频按素材原始比例显示。视频静音循环播放，提供播放与暂停按钮；按用户要求移除首屏放大观看入口。离屏或标签页隐藏时暂停，用户手动暂停后不会自行恢复。系统启用减少动态效果时默认不自动播放，但仍可手动播放。不增加播放器库或后端依赖，JavaScript 不可用时保留浏览器原生控件。

## 页面间距

本页通过 `--sb-section-space` 统一区块上下间距：桌面 64px、平板 52px、手机 40px。同底色的连续区块避免两份 padding 叠加；工作闭环与角色区之间分别使用 48px、36px、32px 的单份间距。标题、卡片、FAQ 与底部入口同步收紧，目录锚点按区块内距补偿，使标题落在固定导航下方。所有规则仅作用于 `.sb-page`，不修改公共样式。

按用户反馈移除页内产品手册入口和底部大幅行动引导。常见问题改为上方标题、下方双列折叠项，手机上顺序排列；页面以精简的相关产品链接衔接原有公共页脚。

## 小程序旋转展台

`miniappScreens` 是独立的界面数据数组。展台使用 CSS perspective/transform 与原生指针事件，不新增框架或后端依赖。

- 8 个场景循环切换，中央手机突出，两侧手机以透视角度退后；支持按钮、场景直达、方向键、Home/End 和横向拖动。
- 当前界面可放大；原有 Web 截图放大逻辑继续复用。
- 场景标题、说明、切换入口和图片版本提示位于手机展台上方，切换场景时同步更新。
- 自动轮播间隔为 5.2 秒。离开可视区域、浏览器页面隐藏或鼠标悬停在手机图片区域时暂停；焦点进入或手动切换后停止，保持用户选中的界面。按用户要求移除轮播播放按钮，保留场景选择、前后切换、拖动与图片放大。
- 跟随 `prefers-reduced-motion` 关闭自动播放和旋转过渡；移动端保留原生竖向页面滚动。
- 该展示只切换图片和文案，不产生产品内的真实业务操作。
