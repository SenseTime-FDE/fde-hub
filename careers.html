商汤生态渠道团队选择平台落地型 FDE：从客户的真实问题出发，贯穿需求诊断、方案设计、系统搭建、上线陪跑与效果复盘。

FDE 在这里不只是一个岗位名称，而是连接客户、产品和伙伴的工作方式：先把代表性场景跑通，再把方法沉淀为可复用资产。

01
Forward Deployed Engineer

FDE 交付工程师

深入客户业务现场，将大模型与 AI 产品能力转化为可部署、可验证、可持续迭代的业务解决方案，并把共性经验反哺产品。

岗位职责

  1. 业务理解与方案定义梳理客户流程、数据、权限和系统边界，将模糊需求拆解为明确的 AI 场景、技术方案和验证目标。
  2. 全流程工程交付推进 Demo / POC 到实际交付，完成模型调用、RAG / Agent 配置、接口对接、部署测试和效果评估。
  3. 现场联调与问题闭环联合客户、销售、伙伴及产品研发，排查接口、数据链路、权限、日志、模型效果与系统稳定性问题。
  4. 经验产品化沉淀交付文档、操作手册、评测方法和可复用组件，并把一线反馈与共性需求带回产品团队。

任职要求

  1. 具备 Python 等编程能力，能够完成接口开发、数据处理、自动化脚本和基础服务搭建。
  2. 理解大模型、Prompt、RAG、Agent 与模型评测等技术，有相关项目或交付实践。
  3. 具备系统集成与问题排查能力，了解 API、数据库、Linux、云环境、容器或企业内部系统对接。
  4. 能与业务负责人和技术团队有效沟通，可在客户现场与不确定场景中快速学习、协同推进并对阶段结果负责。

岗位职责

  1. 参与 AI 应用交付协助理解客户需求，参与大模型、Agent 与 AI 应用的 Demo 搭建、测试、部署和交付。
  2. 参与方案验证开展 Prompt 调优、RAG 配置、接口调用测试、模型效果评估和问题反馈。
  3. 协助现场排障在指导下排查接口、日志、数据链路、权限配置和模型服务等项目问题。
  4. 沉淀与反馈整理部署文档、操作手册、FAQ 和项目复盘，收集一线反馈支持产品持续优化。

任职要求

  1. 本科及以上在读，计算机、人工智能、软件工程、自动化等相关专业优先。
  2. 熟悉 Python、JavaScript / TypeScript、Java、Go 等至少一门语言；使用过 Codex、Claude Code 等 AI 编程工具完成项目者优先。
  3. 能清楚说明课程、竞赛、实习或个人项目的目标、本人贡献、协作过程、结果与实际价值。
  4. 对 AI 应用落地和 FDE 工作有真实兴趣，自驱、可靠、愿意协作；每周实习 4 天及以上、连续 6 个月以上优先。

面试会重点了解 AI 实践、项目表达与协作方式，以及你真正想做的事情和未来职业规划；兴趣与方向匹配比单纯罗列工具更重要。

  4. 熟练使用 AI 文案、生图、剪辑和数据分析工具；数据敏感、自驱，能够跨部门多线程推进。
