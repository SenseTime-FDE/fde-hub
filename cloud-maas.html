04Token Plan·TOKEN PLAN

按人订阅，一份积分多处通用

跨模型、跨模态的统一额度：5 小时、每周、月度三层额度，额外用量开关由管理员按业务设置。

是什么

按人按月订阅的模型使用权益

一份订阅获得共享积分，跨模型、跨模态通用。

在哪里用

API 与编程工具

一个席位，一组模型，跨模型、跨模态通用。

怎么选档

多档订阅，按使用强度选

档位越高，额度越多、并发越高；国内与海外套餐各自独立。

对比Token Plan 订阅API 按量
怎么付按人按月订阅，多档可选充值余额，按实际调用量扣费
怎么计量积分：跨模型、跨模态共享各模型按计价维度计费
上限5 小时 · 每周 · 月度三层额度余额内按量调用，受接口限频
适合人：高频、稳定的日常使用系统：业务集成、批量与波动任务
一句话

人用订阅，系统用按量：订阅让个人成本可预期，按量让系统成本随业务走，一个账户里并存。

06企业与伙伴·ENTERPRISES & PARTNERS

企业把权益穿透到人，伙伴用同一种结算

企业 · 四层账户

集团统一采购，建组织树，向下级下发，看全集团用量。
分子公司承接集团权益，开通部门，划拨与代开通。
部门席位绑定到人，应用建 Key，按成员查询用量。
个人一个席位与套餐额度，登录即用，额度一目了然。

伙伴 · 同一种结算

渠道伙伴转售商汤 Token Plan，经营订阅、续费与升档；客户直签归伙伴。

服务伙伴服务以 Token Plan 计价收费，一次性人天变为可续费订阅。
